本目录汇总 AI Agent 领域最顶级的必读论文、开源仓库、官方文档与推荐学习资源。

---

## 📜 1. 经典必读论文 (Must-Read Papers)

### 🤖 规划与 Reasoning
1. **ReAct: Synergizing Reasoning and Acting in Language Models** (Yao et al., 2022)
   - *推荐理由*：Agent 领域的奠基之作，首次提出将 Reasoning 与 Action 结合的范式。
2. **Reflexion: Language Agents with Verbal Reinforcement Learning** (Shinn et al., 2023)
   - *推荐理由*：讲解 Agent 如何通过文本反馈进行自我反思与迭代优化。
3. **Plan-and-Solve Prompting: Improving Zero-Shot Chain-of-Thought Reasoning by Large Language Models** (Wang et al., 2023)
   - *推荐理由*：提出先制定全局计划再逐步执行的规划模式。

### 🛠️ 工具使用 (Tool Use)
1. **Toolformer: Language Models Can Teach Themselves to Use Tools** (Schick et al., 2023)
   - *推荐理由*：探索模型如何自主决定在什么位置、何时调用工具。

### 👥 多 Agent 协作 (Multi-Agent Systems)
1. **Generative Agents: Interactive Simulacra of Human Behavior** (Park et al., 2023)
   - *推荐理由*：斯坦福著名的“小镇居民”论文，展现了具备记忆、反思与社交能力的多 Agent 系统。
2. **CAMEL: Communicative Agents for "Mind" Exploration of Large Language Model Society** (Li et al., 2023)
   - *推荐理由*：探索两个 Agent 自主对话合作完成任务的机制。
