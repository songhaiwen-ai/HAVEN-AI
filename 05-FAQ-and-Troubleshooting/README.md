## 📝 记录模板 (Template)

遇到新问题时，请使用以下格式记录：

```markdown
### [问题分类] 简要描述问题标题

- **时间**：YYYY-MM-DD
- **环境**：Python 3.x / LangChain 0.x / Windows 11
- **现象 / 报错信息**：
  ```text
  [贴出具体报错 Traceback 信息]
  ```
- **根本原因 (Root Cause)**：
  分析为什么会发生这个错误。
- **解决方案 (Solution)**：
  具体的代码修改或配置调整方法。
```
